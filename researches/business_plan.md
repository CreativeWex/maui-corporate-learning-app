# Бизнес-план: Система управления обучением (LMS) для корпоративного сектора

> **Платформа:** .NET MAUI (Android / iOS / macCatalyst)  
> **Архитектура:** MVVM + Service Layer + Repository  
> **Навигация:** Shell (`AppShell.xaml`), `Shell.GoToAsync()`  
> **Дата:** 2026-05-25

---

## 1. Общая концепция

Корпоративная LMS — мобильное приложение для организации и прохождения обучения внутри компании. Система охватывает весь цикл: от назначения курса HR-специалистом до получения сертификата сотрудником.

### Ключевые роли

| Роль | Основная задача |
|------|----------------|
| **Сотрудник** | Проходить назначенные и выбранные курсы |
| **Менеджер** | Контролировать прогресс команды, назначать обучение |
| **HR / L&D** | Управлять контентом, формировать программы обучения |
| **Администратор** | Настройка системы, управление пользователями |

### Типы контента

- Текстовые статьи (Markdown)
- Карточки (flashcards)
- Тесты и квизы (single/multiple choice)
- Инфографика (изображения с аннотациями)
- Ментальные карты
- Изображения (опционально)

### Ключевые функции

- Назначение обучения (HR → сотрудник)
- Трекинг прогресса (сотрудник и менеджер)
- Сертификация по завершении
- Геймификация (бейджи, очки, рейтинги)

## 4. Описание экранов

---

### Экран 1: SplashPage

**Назначение:** Точка входа в приложение. Показывает логотип, инициализирует DI-контейнер, проверяет наличие и валидность токена аутентификации.

**Роль:** Все пользователи

**UI-компоненты:**
- Логотип компании (Image, центр экрана)
- Название приложения (Label, H1)
- Индикатор загрузки (ActivityIndicator)
- Версия приложения (Label, мелкий шрифт, снизу)

**Бизнес-правила:**
- Если токен существует и не истёк → навигация на `HomePage`
- Если токен отсутствует или истёк → навигация на `LoginPage`
- Минимальное время показа: 1.5 сек (UX-норма)

**Навигация:**
- Вход: стартовая точка приложения
- Выход: `LoginPage` или `HomePage`

**Модели данных:** `AuthToken { Token, ExpiresAt, UserId }`

**ViewModel:** `SplashViewModel`

---

### Экран 2: LoginPage

**Назначение:** Аутентификация пользователя. Поддерживает ввод корпоративного email и пароля. Опционально — кнопка SSO (Single Sign-On через корпоративный IdP).

**Роль:** Все пользователи

**UI-компоненты:**
- Логотип и заголовок (Image + Label)
- Поле Email (Entry, keyboard=Email, placeholder)
- Поле Пароль (Entry, IsPassword=true)
- Кнопка «Войти» (Button, основной акцент)
- Ссылка «Войти через корпоративный портал» (TapGestureRecognizer)
- Ссылка «Забыли пароль?» (TapGestureRecognizer)
- ActivityIndicator во время запроса

**Бизнес-правила:**
- Email должен быть валидным (regex)
- Пароль — минимум 6 символов
- После 5 неудачных попыток — блокировка на 15 минут
- При успехе токен сохраняется в `SecureStorage`
- Роль пользователя (Employee / Manager / HR / Admin) определяется из ответа сервера и направляет на соответствующий начальный экран

**Навигация:**
- Вход: `SplashPage` (redirect), прямой запуск
- Выход: `HomePage` (все роли), `TeamDashboardPage` (менеджер, если настроено)

**Модели данных:** `LoginRequest { Email, Password }`, `AuthResponse { Token, ExpiresAt, User }`

**ViewModel:** `LoginViewModel`

---

### Экран 3: HomePage (Главная)

**Назначение:** Персональный дашборд сотрудника. Мотивационный экран, отображающий прогресс, активные курсы и достижения, чтобы побудить к обучению каждый день.

**Роль:** Сотрудник (основной), адаптирован для всех ролей

**UI-компоненты:**
- Приветствие с именем пользователя (Label: «Привет, Анна!»)
- Streak-плашка (Label + Icon: «🔥 7 дней подряд»)
- Горизонтальный список «Продолжить обучение» (CollectionView, карточки курсов)
  - Обложка курса (Image)
  - Название и категория (Label)
  - Прогресс-бар (ProgressBar)
  - Процент завершения (Label)
- Секция «Новые назначения» (CollectionView, 2 карточки)
- Блок статистики (Grid 2×2):
  - Завершено курсов
  - Часов обучения
  - Бейджей получено
  - Место в рейтинге
- Bottom Navigation Bar: Главная / Каталог / Прогресс / Профиль

**Бизнес-правила:**
- «Продолжить обучение» — курсы с прогрессом > 0% и < 100%, отсортированные по дате последней активности
- «Новые назначения» — курсы с `AssignedAt` в последние 7 дней
- Streak увеличивается при активности (открытие урока) каждый день

**Навигация:**
- Вход: `SplashPage`, `LoginPage`
- Карточка курса → `CourseDetailPage`
- Bottom tab «Каталог» → `CatalogPage`
- Bottom tab «Прогресс» → `MyProgressPage`
- Bottom tab «Профиль» → `ProfilePage`

**Модели данных:** `CourseProgress { CourseId, Title, CoverUrl, ProgressPercent, LastAccessedAt }`, `UserStats { CompletedCourses, TotalHours, Badges, LeaderboardRank }`

**ViewModel:** `HomeViewModel`

### Экран 4: CatalogPage (Каталог курсов)

**Назначение:** Поиск и просмотр доступных курсов. Позволяет сотруднику самостоятельно выбрать дополнительное обучение помимо назначенного.

**Роль:** Сотрудник

**UI-компоненты:**
- SearchBar (placeholder: «Найти курс...»)
- Горизонтальный ScrollView с чипами-фильтрами:
  - Все / Назначенные / IT / Soft Skills / Compliance / Менеджмент
- Переключатель вида: плитка / список (SegmentedControl или ImageButton)
- CollectionView с карточками курсов:
  - Обложка, категория-чип, название, автор, длительность, рейтинг ⭐, прогресс-бар (если начат)
- Индикатор загрузки (ActivityIndicator)
- Сообщение «Ничего не найдено» (Label, при пустом результате)

**Бизнес-правила:**
- Поиск — по названию и описанию курса (debounce 300 мс)
- Назначенные курсы помечаются бейджем «Назначен» и дедлайном
- Курсы, просроченные по дедлайну, выделяются красным
- Сортировка по умолчанию: назначенные → новые → популярные

**Навигация:**
- Вход: Bottom tab с `HomePage`
- Карточка курса → `CourseDetailPage`

**Модели данных:** `Course { Id, Title, Category, CoverUrl, AuthorName, DurationMinutes, Rating, IsAssigned, DeadlineDate, ProgressPercent }`

**ViewModel:** `CatalogViewModel`

---

### Экран 5: CourseDetailPage (Детальная страница курса)

**Назначение:** Полная информация о курсе. Ключевая точка принятия решения: начать, продолжить или записаться на курс.

**Роль:** Сотрудник

**UI-компоненты:**
- Hero-изображение курса (Image, верхние 35% экрана)
- Кнопка «Назад» (←)
- Название курса (Label, H1)
- Автор и организация (Label + Avatar)
- Метаданные (Grid): длительность / уроков / уровень сложности / рейтинг
- Описание курса (Label, expandable)
- ProgressBar + «X из Y модулей завершено»
- Список модулей (CollectionView):
  - Иконка типа контента (статья / карточки / тест)
  - Название модуля
  - Длительность
  - Статус: не начат / в процессе / завершён (иконки)
- Кнопка CTA: «Начать» / «Продолжить» / «Повторить» (Button, фиксированная снизу)

**Бизнес-правила:**
- Модули проходятся последовательно (следующий заблокирован до завершения предыдущего)
- Если курс назначен — отображается дедлайн и предупреждение при < 3 днях
- Кнопка CTA ведёт к первому незавершённому модулю
- После завершения всех модулей — автоматически предлагается финальный тест (если есть)

**Навигация:**
- Вход: `CatalogPage`, `HomePage`
- Кнопка CTA / карточка модуля → `LessonPage` или `QuizPage`
- После финального теста → `QuizResultPage`

**Модели данных:** `CourseDetail { ...Course, Description, Modules[] }`, `Module { Id, Title, Type, DurationMin, Status }`

**ViewModel:** `CourseDetailViewModel`

### Экран 6: LessonPage (Просмотр урока)

**Назначение:** Основной экран обучения. Отображает контент урока в нужном формате и фиксирует факт просмотра.

**Роль:** Сотрудник

**UI-компоненты:**
- Заголовок урока (Label, H2) + прогресс «Урок 3 / 8» (Label)
- Линейный прогресс-бар сверху (ProgressBar)
- Контентная область (ScrollView):
  - **Тип «статья»:** WebView с Markdown-рендерингом
  - **Тип «карточки»:** CarouselView (flip-анимация, лицо / оборот)
  - **Тип «инфографика»:** PinchZoom Image + аннотации
  - **Тип «ментальная карта»:** интерактивный SVG-граф (кастомный DrawingView или WebView)
- Кнопки навигации: «← Предыдущий» / «Следующий →» (Button)
- Кнопка «Отметить как завершённый» (CheckBox + Label)

**Бизнес-правила:**
- Факт прочтения фиксируется при скролле до конца (80%+ контента) или нажатии «Завершить»
- Для карточек — необходимо перелистать все карточки
- Время нахождения на экране записывается в `LearningSession`
- Без интернета — контент загружается из локального кэша (SQLite blob)

**Навигация:**
- Вход: `CourseDetailPage`
- «Следующий» → следующий `LessonPage` или `QuizPage`
- «Назад» → `CourseDetailPage`

**Модели данных:** `Lesson { Id, Title, Type, Content, DurationMin }`, `LearningSession { LessonId, StartedAt, CompletedAt, TimeSpentSec }`

**ViewModel:** `LessonViewModel`

---

### Экран 7: QuizPage (Тест / Квиз)

**Назначение:** Проверка знаний по пройденному материалу. Мотивирует закрепить материал через интерактивные вопросы.

**Роль:** Сотрудник

**UI-компоненты:**
- Заголовок теста и название курса (Label)
- Прогресс теста: «Вопрос 4 из 10» + ProgressBar
- Таймер (Label, опционально, если тест ограничен по времени)
- Блок вопроса:
  - Текст вопроса (Label, H3)
  - Изображение к вопросу (Image, опционально)
- Блок ответов (RadioButtonGroup или CheckBoxGroup):
  - **Single choice:** RadioButton-список
  - **Multiple choice:** CheckBox-список
  - **True/False:** два крупных Button
- Кнопка «Ответить» / «Далее» (Button, активна после выбора ответа)
- Кнопка «Пропустить» (Label-ссылка, если разрешено)

**Бизнес-правила:**
- Вопросы показываются по одному
- «Ответить» активна только после выбора варианта
- После ответа — подсветка: зелёный (верно) / красный (неверно) + краткое объяснение
- Порядок вариантов ответа рандомизируется
- Финальный тест курса: попытки ограничены (по умолчанию 3)

**Навигация:**
- Вход: `CourseDetailPage`, `LessonPage`
- После последнего вопроса → `QuizResultPage`
- «Назад» → `CourseDetailPage` (с предупреждением о потере прогресса)

**Модели данных:** `Quiz { Id, Title, TimeLimit, Questions[] }`, `Question { Id, Text, ImageUrl, Type, Options[] }`, `Answer { QuestionId, SelectedOptions[], IsCorrect }`

**ViewModel:** `QuizViewModel`

---

### Экран 8: QuizResultPage (Результаты теста)

**Назначение:** Итоговый экран после прохождения теста. Показывает результат, детальный разбор и мотивирует к следующему шагу.

**Роль:** Сотрудник

**UI-компоненты:**
- Анимированная иконка результата (CheckMark ✅ / Warning ⚠️ анимация)
- Круговой прогресс-индикатор с баллами (CircularProgressView или Canvas)
- Текст итога: «Отлично! 90%» / «Не прошли. 45%» (Label, H1)
- Статистика (Grid 2×2): Верных / Неверных / Пропущенных / Время
- Список вопросов с разбором (CollectionView, collapsible):
  - Текст вопроса
  - Ваш ответ (зелёный/красный)
  - Правильный ответ
  - Объяснение
- Кнопка «Продолжить курс» (если курс не завершён)
- Кнопка «Пройти ещё раз» (если не набран проходной балл и есть попытки)
- Конфетти-анимация (при успешном прохождении)

**Бизнес-правила:**
- Проходной балл: 80% (настраивается HR)
- При провале и исчерпании попыток — курс блокируется, HR получает уведомление
- При успешном прохождении финального теста — генерируется сертификат
- Результат сохраняется в истории и учитывается в статистике

**Навигация:**
- Вход: `QuizPage`
- «Продолжить курс» → `CourseDetailPage`
- «Пройти ещё раз» → `QuizPage`
- При получении сертификата → предложение перейти на `CertificatesPage`

**Модели данных:** `QuizResult { QuizId, Score, PassedPercent, Passed, AttemptNumber, AnswerDetails[] }`

**ViewModel:** `QuizResultViewModel`

### Экран 9: MyProgressPage (Мой прогресс)

**Назначение:** Личная аналитика обучения. Мотивирует через визуализацию роста и помогает сотруднику понять, сколько он достиг.

**Роль:** Сотрудник

**UI-компоненты:**
- Заголовок «Мой прогресс» (Label, H1)
- Период (SegmentedControl): Неделя / Месяц / Квартал / Всё время
- Сводная статистика (HorizontalScrollView, карточки):
  - Завершено курсов
  - Часов обучения
  - Streak (текущий и максимальный)
  - Место в рейтинге
- Streak-календарь (Grid 7×N, цветовые ячейки по активности — GitHub-style)
- График активности (BarChart / LineChart, кастомный Canvas или библиотека)
- Список завершённых курсов (CollectionView):
  - Название, дата завершения, балл за финальный тест
- Прогресс по назначенным курсам (CollectionView с прогресс-барами и дедлайнами)

**Бизнес-правила:**
- Streak считается как количество дней подряд с активностью (≥ 1 урок)
- Данные за период берутся из `LearningSession` и агрегируются локально
- Курсы с просроченным дедлайном выделяются красным

**Навигация:**
- Вход: Bottom tab с `HomePage`
- Завершённый курс → `CourseDetailPage`
- Секция «Достижения» (если есть) → `AchievementsPage`

**Модели данных:** `ProgressStats { Period, CompletedCourses, TotalHours, CurrentStreak, MaxStreak, Rank }`, `DailyActivity { Date, MinutesSpent }`

**ViewModel:** `MyProgressViewModel`

### Экран 10: CertificatesPage (Сертификаты)

**Назначение:** Хранилище полученных сертификатов. Даёт сотруднику подтверждение квалификации и возможность поделиться достижением.

**Роль:** Сотрудник

**UI-компоненты:**
- Заголовок «Мои сертификаты» (Label, H1)
- Счётчик сертификатов (Label: «У вас 5 сертификатов»)
- CollectionView с карточками сертификатов:
  - Превью сертификата (Image)
  - Название курса (Label)
  - Дата выдачи (Label)
  - Организация-эмитент (Label)
  - Кнопки: «Скачать PDF» / «Поделиться»
- Пустое состояние: иллюстрация + «Завершите курс, чтобы получить первый сертификат»

**Бизнес-правила:**
- Сертификат генерируется автоматически после прохождения финального теста с баллом ≥ 80%
- PDF содержит: имя сотрудника, название курса, дату, подпись HR-директора, QR-код верификации
- Сертификаты хранятся локально (SQLite blob) и синхронизируются с сервером
- Кнопка «Поделиться» открывает нативный Share Sheet

**Навигация:**
- Вход: `MyProgressPage`, `QuizResultPage`, Bottom tab
- «Скачать» → нативный файловый менеджер
- «Поделиться» → нативный Share Sheet

**Модели данных:** `Certificate { Id, CourseId, CourseName, IssuedAt, PdfUrl, QrCode }`

**ViewModel:** `CertificatesViewModel`

### Экран 11: AchievementsPage (Достижения)

**Назначение:** Геймификация обучения. Показывает заработанные бейджи и прогресс к следующим, мотивируя через принцип «коллекционирования».

**Роль:** Сотрудник

**UI-компоненты:**
- Заголовок «Достижения» (Label, H1)
- Уровень и общие очки (Label + ProgressBar до следующего уровня)
  - Пример: «Уровень 5 — Исследователь | 2450 / 3000 XP»
- Вкладки (TabBar): Все / Получено / Заблокировано
- Grid 3-колонки с бейджами:
  - **Полученный:** цветная иконка + название + дата получения (при тапе)
  - **Заблокированный:** серая иконка + условие получения (при тапе)
- Всплывающий BottomSheet при тапе на бейдж:
  - Большая иконка
  - Название и описание
  - Прогресс к получению (ProgressBar)

**Бизнес-правила (примеры бейджей):**
- «Первый шаг» — завершить первый урок
- «Отличник» — сдать тест на 100%
- «Марафонец» — streak 30 дней подряд
- «Полиглот» — пройти 3 курса разных категорий
- «Быстрый старт» — завершить курс за 24 часа после назначения
- Бейдж начисляет XP (от 50 до 500 очков)

**Навигация:**
- Вход: `HomePage`, `MyProgressPage`
- Кнопка «Рейтинг» → `LeaderboardPage`

**Модели данных:** `Achievement { Id, Name, Description, IconUrl, XpReward, UnlockedAt?, Condition }`, `UserLevel { Level, LevelName, CurrentXp, XpToNext }`

**ViewModel:** `AchievementsViewModel`

### Экран 12: LeaderboardPage (Рейтинг)

**Назначение:** Соревновательный элемент геймификации. Показывает позицию сотрудника в команде/компании, стимулирует обучение через социальное сравнение.

**Роль:** Сотрудник

**UI-компоненты:**
- Заголовок «Рейтинг» (Label, H1)
- Переключатель: Моя команда / Компания (SegmentedControl)
- Период (SegmentedControl): Неделя / Месяц / Всё время
- Топ-3 подиум (3 карточки с аватарами, именами, очками — стиль пьедестала)
- Позиция текущего пользователя (выделенная карточка, «Вы на 7 месте»)
- ListView с позициями 4–N:
  - Позиция (Label), Аватар, Имя, Отдел, Очки XP, Бейджей
- Pull-to-refresh

**Бизнес-правила:**
- XP начисляются за: завершение уроков (+10 XP), прохождение тестов (от +20 до +100 XP в зависимости от балла), получение бейджей, streak-бонусы
- Рейтинг пересчитывается раз в час на сервере
- Анонимизация: пользователь может скрыть себя из рейтинга в настройках профиля

**Навигация:**
- Вход: `AchievementsPage`, `HomePage`
- Тап на другого пользователя → BottomSheet с его публичным профилем (бейджи, топ-курсы)

**Модели данных:** `LeaderboardEntry { Rank, UserId, DisplayName, AvatarUrl, Department, TotalXp, BadgeCount, IsCurrentUser }`

**ViewModel:** `LeaderboardViewModel`

### Экран 13: TeamDashboardPage (Дашборд команды)

**Назначение:** Инструмент менеджера для мониторинга обучения команды. Позволяет быстро выявить отстающих и оценить общий прогресс.

**Роль:** Менеджер / Руководитель

**UI-компоненты:**
- Заголовок «Моя команда» + название отдела (Label)
- Сводка (Grid 2×2):
  - Сотрудников в команде
  - Средний прогресс (%)
  - Курсов назначено
  - Просроченных дедлайнов (красный)
- Секция «Требуют внимания» (CollectionView, сотрудники с риском просрочки):
  - Аватар, имя, курс, дедлайн, прогресс-бар (красный при < 30%)
  - Кнопка «Напомнить» (отправка пуш-уведомления)
- Список всех сотрудников (CollectionView):
  - Аватар, имя, назначенных курсов, завершённых, % выполнения
  - Тап → детальный профиль сотрудника
- FAB «Назначить курс» (+)

**Бизнес-правила:**
- «Зона риска»: прогресс < 30% при оставшемся дедлайне ≤ 3 дней
- Менеджер видит только своих прямых подчинённых (иерархия из HR-системы)
- Кнопка «Напомнить» доступна не чаще 1 раза в 24 часа на одного сотрудника

**Навигация:**
- Вход: `LoginPage` (для роли Manager), Bottom tab
- FAB → `AssignCoursePage`
- Тап на сотрудника → BottomSheet с детальной статистикой

**Модели данных:** `TeamMember { UserId, Name, AvatarUrl, AssignedCourses, CompletedCourses, OverallProgress, IsAtRisk }`, `TeamStats { TotalMembers, AvgProgress, AssignedCount, OverdueCount }`

**ViewModel:** `TeamDashboardViewModel`

### Экран 14: AssignCoursePage (Назначение курса)

**Назначение:** Инструмент HR/L&D и менеджера для назначения обязательного обучения. Обеспечивает соответствие корпоративным требованиям и трекинг выполнения.

**Роль:** HR / L&D специалист, Менеджер

**UI-компоненты:**
- Заголовок «Назначить обучение» (Label, H1)
- Шаг 1 — Выбор курса:
  - SearchBar + фильтры по категории
  - CollectionView с курсами (одиночный выбор, RadioButton)
- Шаг 2 — Выбор получателей:
  - SegmentedControl: Сотрудник / Группа / Отдел
  - SearchBar + CollectionView с CheckBox для множественного выбора
- Шаг 3 — Настройки:
  - DatePicker «Дедлайн»
  - Switch «Обязательное обучение»
  - Switch «Напоминания» (за 7 / 3 / 1 день)
  - TextEditor «Сообщение для сотрудника» (опционально)
- Итоговая карточка-сводка (назначаем «X» курс → «Y» сотрудникам до «Z» даты)
- Кнопка «Назначить» (Button, акцентный)

**Бизнес-правила:**
- Дедлайн не может быть раньше завтрашнего дня
- Нельзя назначить курс, который сотрудник уже проходит (предупреждение)
- При нажатии «Назначить» — пуш-уведомления рассылаются получателям
- Журнал назначений сохраняется с ID инициатора и временной меткой

**Навигация:**
- Вход: `TeamDashboardPage` (FAB), меню HR-раздела
- После успешного назначения → `TeamDashboardPage` с toast-уведомлением «Курс назначен»

**Модели данных:** `AssignmentRequest { CourseId, RecipientIds[], DeadlineDate, IsMandatory, ReminderDays[], Message }`, `Assignment { Id, CourseId, UserId, AssignedById, DeadlineDate, AssignedAt }`

**ViewModel:** `AssignCourseViewModel`

### Экран 15: ProfilePage (Профиль и настройки)

**Назначение:** Персональные данные, настройки приложения и уведомлений. Также точка выхода из системы.

**Роль:** Все пользователи

**UI-компоненты:**
- Аватар (Image, круглый) + кнопка смены фото
- Имя и должность (Label H2 + Label)
- Email и отдел (Label, вторичный цвет)
- Секция «Обучение»:
  - Уровень и XP (ProgressBar)
  - Кнопка «Мои достижения» → `AchievementsPage`
  - Кнопка «Рейтинг» → `LeaderboardPage`
- Секция «Настройки уведомлений» (ListView):
  - Toggle: Напоминания о курсах
  - Toggle: Новые назначения
  - Toggle: Достижения и бейджи
  - Toggle: Рейтинг (обновления позиции)
- Секция «Приложение»:
  - Выбор языка (Picker: Русский / English)
  - Переключатель темы (Toggle: Светлая / Тёмная)
  - Версия приложения (Label)
- Кнопка «Выйти» (Button, деструктивный стиль, красный)

**Бизнес-правила:**
- Смена аватара — из галереи или камеры (через MediaPicker)
- Изменения настроек уведомлений применяются немедленно (сохраняются в Preferences)
- «Выйти» — удаляет токен из SecureStorage, очищает кэш, редиректит на `LoginPage`
- Анонимизация в рейтинге — переключатель в этой секции

**Навигация:**
- Вход: Bottom tab (доступен из любого экрана)
- «Мои достижения» → `AchievementsPage`
- «Рейтинг» → `LeaderboardPage`
- «Выйти» → `LoginPage`

**Модели данных:** `UserProfile { Id, Name, Position, Department, Email, AvatarUrl, Level, TotalXp }`, `AppSettings { Language, Theme, NotificationPreferences }`

**ViewModel:** `ProfileViewModel`
